# Support

This document outlines how to get help and report issues.

---

## Read this before creating an issue

Before opening an issue, please take your time to check the following sections:

1. **Read the Documentation**: Read the [README](README.md) and [CONTRIBUTING](CONTRIBUTING.md) guides.
2. **Search for Existing Issues**: Search for existing open and closed issues on the [GitHub Issues](https://github.com/Josu-A/iw7-mods/issues) page.

---

## Reporting Bugs

If you find a bug, open a **[Bug Report](.github/ISSUE_TEMPLATE/01-bug-report.md)** using the GitHub Issue template and provide all the necessary details.

---

## Request a Feature

If you want to improve this project, open a **[Feature Request](.github/ISSUE_TEMPLATE/02-feature-request.md)** using the GitHub Issue template.
